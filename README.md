One line giving the funniest excuse a robot vacuum could offer for
missing a spot — for the
[The Robot Vacuum's Best Excuse](https://make.fun/bounty/u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214)
bounty on make.fun.

## The excuse

> That corner and I have an agreement: I don't touch it, and it doesn't tell you about the sock I ate in March.

## How it works

`main.ts` writes the excuse to `/output/entry.txt` (109 characters, inside the
140-character gate). The joke is a cover-up deal: the vacuum leaves the
corner alone, and in return the corner keeps quiet about the sock the
vacuum ate in March. It is rooted in the vacuum's own world — a missed
spot, a sock eaten off the floor — told in the vacuum's deadpan
first-person voice, with the turn landing on the last clause.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
